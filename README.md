# Parima's Birthday Website

## Folder structure
- index.html : page layout (no need to edit)
- css/style.css : colors and design
- js/content.js : EDIT THIS. Photos, videos, songs, candle wishes, letter
- js/main.js : prank, cake, countdown logic
- assets/images/memories/ : memory photos
- assets/images/parima-solo/ : Parima's solo photos
- assets/images/spotify-codes/ : Spotify code images (optional)
- assets/videos/ : memory videos (mp4, keep each under ~20 MB for mobile)

## Steps
1. Copy photos/videos into the folders above and set the file names in js/content.js.
2. Spotify: open the song > Share > Copy link. The ID is the part after /track/ and before the ?. Put it in `spotify: "..."`.
3. Open index.html to test. Then host it (Netlify Drop, GitHub Pages) and share the link; test it on your phone first.
